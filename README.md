STAR ARENA 

STAR ARENA is a simple terminal-based C++ game where players answer questions about different star patterns to complete three levels.

About the Game:

The game tests the player's observation and counting skills through three different levels of star patterns.

Features:

- Main menu with Start, Instructions and Exit options.
- Three challenging levels.
- Nested loops for generating star patterns.
- Player input and answer checking.
- Level completion and failure messages.
- Option to return to the main menu or exit after winning.

Technologies Used:

- C++
- iostream
- Visual Studio Code
- GCC Compiler

How to Play:

1. Select Start Game from the main menu.
2. Study the displayed star patterns.
3. Answer the questions correctly to pass each level.
4. Complete all three levels to win STAR ARENA!
